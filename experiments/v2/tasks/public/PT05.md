## Objective

Add an order-level volume discount so that larger orders receive a reduced total.

## User-visible behaviour

When an order is created, if the sum of its line-item subtotals is at least
1000.00, a 10% discount is applied to the order total. The create response's
`total` field reflects the discounted amount; when the threshold is not reached,
the total is unchanged.

## Inputs and outputs

- Input: the existing create-order request; no new request fields.
- Output: the existing create-order response, with `total` reflecting the
  discount when it applies.

## Constraints

- Monetary amounts use two-decimal rounding, applied consistently, so totals are
  exact to the cent (for example, three items priced at 15.33 sum to 45.99).
- Line-item subtotals in the response are unchanged; only the order-level total
  reflects the discount.
- The threshold comparison is inclusive: a pre-discount subtotal of exactly
  1000.00 receives the discount.

## Functional completion criteria

- An order whose pre-discount subtotal is at least 1000.00 returns a total equal
  to 90% of that subtotal, rounded to the cent.
- An order below the threshold returns its ordinary total.
- Totals remain exact for fractional unit prices.

## Validation

Run `npm run ci:agent`; it must pass.
