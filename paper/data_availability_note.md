# Data Availability

- Repository: https://github.com/thakkarkeyur/afci-bench
- Archive (Zenodo DOI): https://doi.org/10.5281/zenodo.19757261
- Release tag: ase2026-artifacts-v1

The archived snapshot contains the AFCI/MAD benchmark, the 12 task specifications, the 48 per-task run artifacts (12 tasks x 4 conditions: baseline, AFCI, baseline_reset, AFCI_reset), the analysis and harness scripts, and sanitized survey aggregates (overall and by role group; no raw client-sensitive responses are released).
